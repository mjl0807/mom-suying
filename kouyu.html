📖 克隆妈妈的声音
如何克隆妈妈的声音（技术说明 · 点击展开）

环境：Mac · conda 环境 GPTSoVITS · 模型仓库 ~/.openclaw/workspace/gpt-sovits（以下 python 命令均在激活该环境后运行）

第 1 步 · 准备数据

cd ~/voice-clone/mom
python split_audio.py      # 长录音按静音切成 3~10 秒短句 → training/wavs/
python transcribe.py       # 自动转写 → training/mom.list（wav路径|mom|zh|文案）

第 2 步 · 提取特征

python prep_features.py   # BERT 文本 + hubert 音频 + 语义 token

第 3 步 · 训练模型（最耗时，CPU 约 5~6 小时）

python train_mom.py       # GPT 15 轮 → SoVITS 30 轮
# 产出：GPT_weights_v2/mom-e15.ckpt + SoVITS_weights_v2/mom_e30_s300.pth

第 4 步 · 生成克隆语音

cd ~/.openclaw/workspace/gpt-sovits
export PYTHONPATH="$PWD:$PWD/GPT_SoVITS"
echo "跟我二哥说，我现在在西双版纳玩呢。" > /tmp/ref_text.txt
echo "龙龙，妈妈想你了，记得按时吃饭。" > /tmp/target_text.txt
python GPT_SoVITS/inference_cli.py \
  --gpt_model GPT_weights_v2/mom-e15.ckpt \
  --sovits_model SoVITS_weights_v2/mom_e30_s300.pth \
  --ref_audio ~/voice-clone/mom/training/wavs/m4a_0008_00.wav \
  --ref_text /tmp/ref_text.txt --ref_language 中文 \
  --target_text /tmp/target_text.txt --target_language 中文 \
  --output_path /tmp/out
# 生成音频在 /tmp/out/output.wav

要点：① 参考文案必须与参考音频实际内容一致；② 停顿放在意群边界（称呼后、整句后），别拆开黏连词组；③ 数据越多音色越像。
