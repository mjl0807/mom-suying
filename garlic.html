新蒜上市

每年5月到6月，属于蒜香的好时节

每年的五月中旬到六月底，菜市场里就会出现一批白生生、皮薄汁多的新蒜。 这时候的蒜还带着泥土的气息，没有经过晾晒风干，水分足、辣味轻， 咬一口脆甜脆甜的，跟老蒜完全不一样。

妈妈说，新蒜最好的吃法就是生吃。剥两瓣，白嫩嫩的，蘸一点酱油就粥吃， 或者拍碎了拌凉菜，那股蒜香清清爽爽，不会像老蒜那样呛得冲鼻子。 每次新蒜上市的季节，妈妈的厨房里就飘着那种特有的、让人安心的蒜香。

🛒 怎么挑新蒜

  • 看外表：外皮白净、没有霉斑，蒜瓣饱满鼓鼓的，捏着紧实
  • 闻味道：淡淡的蒜香，不刺鼻，没有酸臭味
  • 掐水分：指甲轻轻一掐能出水，说明新鲜
  • 哪里买：盒马、叮咚买菜、菜市场、社区团购都能买到，5-6月大量上市
💡 保存小贴士

新蒜水分大，不耐放。买回来最好放在阴凉通风处，一周内吃完。 如果想多存一些，可以剥干净后泡在醋里做糖蒜，或者切碎用油封起来放冰箱，做菜的时候直接挖一勺。

🍳 新蒜的拿手做法

🥗 糖醋新蒜

最简单的做法，保留了新蒜最鲜嫩的口感。下粥神器。

  • 新蒜剥皮，洗净沥干
  • 用盐腌30分钟，杀出水分
  • 米醋 + 白糖按 3:1 调匀，烧开后放凉
  • 把蒜放进干净的玻璃瓶，倒入糖醋汁没过蒜瓣
  • 冰箱冷藏3天后就能吃，一周后味道最好

🥬 蒜蓉青菜

新蒜拍碎，热油爆香，绿叶菜下锅翻炒几下就出锅。

  • 新蒜3-4瓣拍碎切末
  • 油热后下蒜末，小火炒出香味（不要炒糊）
  • 放洗好的青菜（菠菜/油菜/空心菜/生菜都可以）
  • 大火快炒，加盐调味，30秒出锅

✨ 妈妈的小窍门：新蒜不用切太碎，拍一下就行，吃起来有颗粒感更香

🍜 蒜香拌面

炎热的夏天，一碗凉拌面，蒜香十足才过瘾。

  • 新蒜捣成蒜泥，加少许盐和香油调匀
  • 面条煮熟过凉水，沥干
  • 蒜泥 + 生抽 + 香醋 + 辣椒油（可选）调成酱汁
  • 浇在面上，撒上葱花和黄瓜丝，拌匀开吃

🫓 蒜香烤饼 / 蒜香面包

新蒜做蒜香黄油，抹在面包或饼上烤一烤，满屋飘香。

  • 新蒜切碎末，黄油室温软化
  • 蒜末 + 黄油 + 少许盐 + 欧芹碎（可选）拌匀
  • 抹在切开的法棍/馒头片/手抓饼上
  • 烤箱180°C烤5-8分钟，或者平底锅煎到两面金黄

🦐 蒜蓉蒸虾 / 蒜蓉蒸茄子

新蒜做蒜蓉酱，蒸什么都好吃。

  • 新蒜多瓣切碎末，小米辣切圈（不吃辣可不放）
  • 热油泼在蒜末上，加生抽、蚝油、糖调成蒜蓉酱
  • 虾开背去虾线，或者茄子切段
  • 铺上蒜蓉酱，上锅蒸8-10分钟
  • 出锅撒葱花，再泼一勺热油
🧄 妈妈的话

"新蒜下来了，买点新蒜，新蒜不辣，做点腊八蒜。"

🌿 新蒜的更多吃法

  • 蒜香排骨：新蒜末 + 生抽 + 料酒 + 蜂蜜腌排骨，烤或炸都香
  • 蒜蓉粉丝蒸扇贝：夜市经典，新蒜蓉铺在扇贝上，蒸出来蒜香浓郁
  • 蒜泥白肉：五花肉煮好切薄片，蘸新蒜泥调的酱汁，肥而不腻
  • 腌糖蒜：新蒜整颗泡糖醋汁，一个月后就是酸甜脆爽的糖蒜
  • 蒜薹炒腊肉：新蒜连蒜薹一起买，蒜薹嫩、腊肉香，绝配下饭菜
